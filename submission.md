### Title
ChargebackDisputeX — Autonomous Adjudicated E-Commerce Chargeback Protocol

### Description (<1000 characters)
ChargebackDisputeX is a decentralized e-commerce escrow and autonomous chargeback protocol on GenLayer. It bridges the critical gap in crypto commerce: irreversible payments and lack of consumer fraud protection.

When disputes occur ("package lost, not received, or fake tracking"), GenLayer validators inspect authoritative carrier tracking portals (DHL, FedEx, UPS, USPS, 17track) via gl.nondet.web.render and resolve claims directly on-chain using an LLM consensus jury.

Consensus strictly binds 100% on discrete logistics enums (DELIVERED_CONFIRMED, LOST_OR_RETURNED, INVALID_OR_UNTRACKED, IN_TRANSIT), preventing LLM phrasing discrepancies. Canonical host whitelisting and tracking code URL binding prevent spoofing and replay attacks. Slashed seller bonds and escrow refunds disburse trustlessly.

Built for Web3 commerce marketplaces, agentic procurement, and cross-border trade. Verified with 15/15 passing gltest unit tests and live on studionet at 0x6Ff70F03341Cba8fF9B8492DbF7d947923D2630B.
